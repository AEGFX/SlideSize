PowerPoint to PDF PPT + PPTX → PDF, in batches

Converts a folder of presentations to PDF using the PowerPoint installed on this computer, so the PDF is drawn by the same program that drew the slides. Each deck is checked before conversion and each PDF is checked afterwards. What could not be checked is reported as not checked.

Microsoft PowerPoint must be installed for PowerPoint-based conversion. A web page cannot start PowerPoint, so a small helper script does it. Nothing is installed. The page writes the helper into the output folder you choose and tells you how to start it. The steps are in section 3.

Where they differ

The PDF page is drawn here by the browser and set against the picture PowerPoint saved of the same slide. The two programs smooth edges, gradients and shadows differently, so the comparison ignores small differences and marks blocks that differ a lot. A marked block is a reason to look, not proof of a fault, and a clean result does not prove the page is right.
