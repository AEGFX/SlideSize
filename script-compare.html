Script Compare

For prompt operators and anyone handed a new version of a script. Drop the version you already have and the new one, and you get the new script with every change marked. Added words in green, cut words struck through, moved paragraphs flagged, every paragraph numbered so you can find it fast. In Word and PowerPoint scripts it also flags formatting changes, so a speaker whose highlight went from yellow to green, or a line that turned bold, is called out. Step through the changes one by one, show only the paragraphs that changed, or copy a Was / Now list to send on.
