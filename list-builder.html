List Builder

Drop a spreadsheet of names and get a PowerPoint deck of lists, N names a slide, sorted by surname or by table. Every name box is a real placeholder on a LIST layout, so one change in Slide Master restyles the whole deck. Made for table plans, delegate lists and credits.

Info
How it works. The header row is detected, the first, last and table columns are guessed from the headers and content, and you can change any of it. Cells are cleaned of stray spaces, non-breaking spaces and line breaks. Names sort case insensitive and accent folded, with Table 2 before Table 10, and surname particles handled UK or Dutch style. The deck has one master and a layout named LIST (plus LIST BREAK when breaking on table) that holds every placeholder, named row.1.name, row.1.table and so on. The slides only carry the text, so position, size, font and colour all come from the layout. Restyle once in Slide Master and the whole deck changes. The .xlsx is read with SheetJS and the .pptx is written with JSZip, both in this tab.
