Font Extractor

When a deck is saved with Embed fonts in the file, PowerPoint packs each font into the .pptx in a compressed wrapper that nothing else can read. Drop the deck here to get them back out as ordinary .ttf or .otf files, see which style slot each one fills, and have any font that is only a subset flagged before you rely on it. You can also save a copy of the deck with the embedded fonts taken out.
